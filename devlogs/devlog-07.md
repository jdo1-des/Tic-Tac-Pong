I made a single player mode so you can play alone. The computer is slower than the player in pong to make it more fair as the computers tracking of the ball is more accurate.
In tic tac toe the computer checks if it can win, if it can't it looks for if the player can win and blocks it, after it will play random moves starting if the center. 
When I made the start menu I mixed up the code to the make the buttons lighter. So when you hovered over one the other would light up. This was an easy fix but funny so I though I'd share it.
I made the single player game modes if seperate files to the 2 player ones. This makes it easy to run them as the files are smaller. I think this will be the last update to my game,
so thank you to anyoen who reads these devlogs and plays my game. Have Fun!
