TLDR: finished the first step by creating a working pong game using python and pygame
<br>
So far I have completed the pong side of my game. This is the first major step in completing the project. I used pygame as it is simple, allows basic graphics, and there is plenty of help online when using it. A major challenge I faced was that I did not have python correctly installed on my computer as I was using VS code to make the game. So when I was trying to run the programme it didn’t work. It took me a while, but after a lot of searching I was able to understand the error message. The fix was quick as I just had to go to the microsoft store and install the latest version of python. After that my game worked fine.
