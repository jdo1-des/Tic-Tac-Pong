# Tic-Tac-Pong


https://github.com/user-attachments/assets/13d351de-6bc4-4bce-a40f-c62626aa1d91


To play just install the tic tac pong file and run start.py. <br><br>
This game is a combination of tic tac toe and pong for two players. Players compete in rounds of pong, the winner of each round gets to place a marker on the tic tac toe board. The pong game also includes 3 power ups (Speed Up, Lengthen, and Slow Down) to spice up the gameplay.
<br><br>
There are 2 gamemodes: 1 player, where you play against the computer; and 2 player, where you play another person on the same device <br>
<br>
# Controls: <br>
1 player: <br>
W/Up arrow: move pong paddle up<br>
S/Down arrow: move pong paddle down<br>
Click: place marker on tic tac toe board
<br><br>
2 player: <br>
Player A (Blue) <br>
W: move pong paddle up<br>
S: move pong paddle down<br>
Click: place marker on tic tac toe board <br>
Player B (Red) <br>
Up arrow: move pong paddle up<br>
Down arrow: move pong paddle down<br>
Click: place marker on tic tac toe board
<br><br>
