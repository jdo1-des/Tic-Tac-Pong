# Tic-Tac-Pong

https://github.com/user-attachments/assets/becea35f-fdc4-4b33-9953-0d050fe7b393

This game is a combination of tic tac toe and pong for two players. Players compete in rounds of pong, the winner of each round gets to place a marker on the tic tac toe board.
<br>
Tech Stack:
<br>
VS code - code editor <br>
Python - code language<br>
Pygame - python library<br>
tkinter - python library<br>
subprocess - python library<br>
pickle - python library<br>
